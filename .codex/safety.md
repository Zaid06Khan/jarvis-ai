# Safety Rules

These rules are the minimum guardrails for Codex work in this repo.

- Do not copy secrets into the repo.
- Do not hardcode API keys, tokens, or credentials.
- Do not replace the existing user-level Codex installation config.
- Do not assume remote services are available unless verified in the current run.
- Do not add destructive automation without explicit review.
- Keep bridge docs sanitized if they refer to local machine or VPS access.
